# AWS Lambda の学習ノート

Lambda は、サーバーを用意せずにコードを実行できるサービスです。イベント（API の呼び出し、ファイルの保存、決まった時刻など）をきっかけに関数が動きます。

## 覚えたこと
- 料金は、呼び出し回数と、実行時間×割り当てたメモリ量で決まります。
- タイムアウトの既定値は3秒です。処理が長いときは設定で延ばします。
- 関数が AWS の他のサービスを操作するには、実行ロール（IAM ロール）に必要な権限を付けます。権限が足りないと AccessDeniedException になります。
- ログは CloudWatch Logs のロググループに出ます。エラーの調査はここから始めます。

## 自分がつまずいた点
S3 に結果を書く関数を、同じバケットのイベントで起動してしまい、関数が繰り返し呼ばれました。入力用と出力用のバケットを別にすると防げます。
