# Amazon DynamoDB の学習ノート

DynamoDB はキーと値で読み書きする NoSQL のデータベースです。テーブルを作るときに、項目を特定するキーを決めます。

## 覚えたこと
- パーティションキーだけで項目を特定する形と、パーティションキーとソートキーの組で特定する形があります。
- 学習記録なら、利用者ID をパーティションキー、記録ID や日付をソートキーにすると、本人の記録だけをまとめて取り出せます。
- 条件付き書き込みを使うと、同じ記録が二重に登録されるのを防げます。
- 読み書きの容量は、オンデマンド（使った分だけ）とプロビジョンド（事前に決める）から選びます。

## 自分がつまずいた点
Scan は全件を読むので、データが増えると遅く高くなります。キーで絞れる Query を使うように直しました。
