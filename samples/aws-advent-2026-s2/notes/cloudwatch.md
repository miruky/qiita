# Amazon CloudWatch の学習ノート

CloudWatch は AWS のリソースやアプリケーションの状態を、メトリクスとログで確かめるサービスです。

## 覚えたこと
- メトリクスは数値の時系列です。Lambda なら Invocations（呼び出し回数）、Errors（エラー数）、Duration（実行時間）などがあります。
- アラームはメトリクスがしきい値を超えたときに状態が変わり、SNS で通知できます。
- ログは CloudWatch Logs のロググループに保存されます。保持期間を決めないと、ずっと残り続けて料金がかかります。
- Logs Insights を使うと、ログをクエリで検索・集計できます。

## 自分がつまずいた点
アラームの「欠落データの扱い」を決めておかないと、データが来ない時間にアラームが思わぬ状態になります。
