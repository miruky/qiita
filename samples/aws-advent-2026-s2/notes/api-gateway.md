# Amazon API Gateway の学習ノート

API Gateway は HTTP の API を作って公開するサービスです。受け取った要求を Lambda などに渡し、応答を返します。

## 覚えたこと
- HTTP API と REST API があります。HTTP API は機能を絞ったぶん料金が安く、JWT オーソライザーと CORS を標準で使えます。
- JWT オーソライザーを付けると、Cognito などが発行したトークンを検証し、通った要求だけを Lambda に渡せます。
- ブラウザから別のドメインの API を呼ぶときは、CORS の設定が必要です。

## 自分がつまずいた点
ステージとルートの関係が最初は分かりにくく、URL の組み立てで何度か 404 を出しました。
