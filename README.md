## ディレクトリ構成

```text
.
├── amazon-lex/           # Amazon Lex チャットボット構築
├── amazon-comprehend/    # Amazon Comprehend 自然言語処理
├── amazon-bedrock/       # Amazon Bedrock 生成AI活用
├── amazon-sagemaker/     # SageMaker AI 機械学習パイプライン
├── aws-sdk-boto3/        # Boto3 によるAWSリソース操作
├── aws-cloudformation/   # CloudFormation テンプレート集
├── aws-cdk/              # CDK (TypeScript) インフラ構築
├── aws-sam/              # SAM サーバーレスアプリケーション
├── aws-code-series/      # CI/CD パイプライン (Code系サービス)
└── terraform/            # Terraform によるインフラ構築
```
